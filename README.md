🛒 E-Commerce Web API (Talabat Inspired)
Designed and developed a robust E-Commerce Web API inspired by Talabat, built using ASP.NET Core.
This project focuses on scalability, clean architecture, and secure API design, while integrating caching and efficient basket management with Redis.

🔧 Key Features
-Product Management: Add, update, delete, and retrieve products.

-Basket Module: Manage user baskets with Redis for fast in-memory caching.

-Order Processing: Place and manage customer orders with validation.

-User Authentication: Secure registration and login with JWT authentication.

-Redis Integration: Optimized caching for improved performance.

-RESTful API Design: Built clean and scalable endpoints.

-Entity Framework Core: Robust ORM for database operations.

-Clean Architecture & SOLID Principles: Ensuring maintainability and testability.

-Dependency Injection: Decoupled, modular service layer.

-AutoMapper: Smooth mapping between DTOs and domain entities.

-Swagger Integration: Interactive API documentation and testing.

🏗️ Tech Stack
Backend Framework: ASP.NET Core

Database: SQL Server + EF Core

Caching: Redis

Authentication: JWT

Mapping: AutoMapper

Documentation: Swagger / OpenAPI
